# PCB

There is no custom PCB for SNAPX.

Everything is off the shelf modules wired together by hand: the AI-Thinker
ESP32-CAM, the ST7735 TFT module, and the pre-wired push button. The only
connections are a handful of jumper wires from the screen and the button to the
ESP32-CAM header pins, which is all in the wiring diagram and the wiring tables in
the main README.

If I ever spin a proper carrier board for this, the design files will go in this
folder.
